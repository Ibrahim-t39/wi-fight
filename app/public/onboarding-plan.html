How Proof AI reads a bill
  1. The photo goes to a model that can read images.
  2. The model describes what it sees before it reads any number. It decides whether the photo is an internet bill at all, and only then returns a fixed set of fields: the provider, the plan name, the monthly plan price, the equipment rental, each extra fee with its amount, the printed total, and the month the promo price ends.
  3. It sorts each fee. For every fee it marks whether the company adds it or whether it is a government tax. Fees with names such as "network enhancement", "infrastructure", "regulatory recovery", and "administrative" are company fees, and the app labels those as possible junk fees.
  4. The app's own code checks the reading without trusting the model. If the model's own description does not mention a bill, nothing is filled in. Fees with no amount are dropped. The plan price, the equipment, and the fees must add up to the printed total, and a fee that breaks the sum is removed. The promo date must look like a month and a year.
  5. You have the last word. You check every field and can edit it before anything is saved, and only the numbers you confirm are kept.

This is a general model that reads text in images, and it was not trained specially on bills, so it can make mistakes.
