# Demo files

Fictional documents for presenting Wi-Fight. The providers, accounts, names, and addresses are made up.
These files are not part of the website. Upload them yourself during a demo, like a real user would.

| File | Use it for |
|---|---|
| `northstar-bill.png` | The main demo. $80 a month, with one fee that is not a tax. Matches the Northstar Fiber 500 plan. |
| `pinecrest-bill.png` | A second bill with two fees that are not taxes. Total $86.99. |
| `northstar-label.png` | A sample broadband label, for slides. |

## How to use a bill

1. On the "Your plan" step, press "Take or choose a photo" and choose a bill from this folder.
2. Proof AI reads the photo. The fields fill in one at a time.
3. Because the app knows these exact files, it also outlines each line on the bill and shows how many values the AI got right.

Use the original file. A screenshot or a re-saved copy still gets read by Proof AI, but the outlines and the check will not show.

To draw the files again, run `tools/make-samples.py` from the `app` folder.
